# twin_screen example

Demonstrates every part of `twin_screen`: the screen state, `TwinPane`, the
fold-aware dialog, window classes and Flutter's own fold-aware widgets.

```sh
flutter run
```

The app runs inside `TwinDebugOverlay`. Tap the round button to see the
current state, and turn on the fold simulator to try every foldable preset,
posture and orientation without the hardware.

On a foldable (or an Android Studio foldable emulator, or the iPhone Duo
simulator on iOS 27.1) the demos follow the real fold.
